# Security Policy

## Scope

BusyBrains OSINT is intended for lawful public-source research and
authorized investigations.

## Reporting a vulnerability

Please report security vulnerabilities privately to the project
maintainer before making them public.

Include:
- A clear description of the issue.
- Steps to reproduce it.
- The affected component and version.
- Potential security impact.

Do not include real people's private information, credentials,
private investigation records, or other sensitive data in reports.

## Responsible use

Users are responsible for obtaining authorization where required,
respecting privacy and applicable laws, and complying with the
terms of services they access.

Security findings and automated observations should be independently
verified. A technical alert is not proof of malicious activity.
